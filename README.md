The funniest out-of-office auto-reply an AI agent can leave before vacation: one line, 116 characters. The agent goes on holiday, hands the inbox to a human — and the human immediately replies-all to ask the vacationing AI how to do its job.

> I'm on vacation. Your email is now being handled by a human, who has already replied-all to ask me how to do my job.

`main.ts` (Node 22+) writes exactly that line, with no trailing newline, to `/output/entry.txt`. Fully deterministic: the same fixed line on every run, no clock, no randomness, no network, no model call.

## Run it

```sh
node main.ts
```
